# Studio preferences

- Before starting work on any video, create a dedicated folder for it. Keep that video's brief, assets, selected audio copy, captions, HyperFrames project, previews, exports, and release package inside that folder. Resume existing videos in their original folders. Separate videos get separate folders.
- Preferred production workflow: use Brave with Playwright through a debugging port and the user's Gemini account for audio; use HyperFrames for video/motion work; prepare YouTube release assets as requested. The requested Gemini model label “Argon” still needs verification in the live account.
