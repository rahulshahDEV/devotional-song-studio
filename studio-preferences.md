# Studio preferences

- Before starting work on any video, create a dedicated folder for it. Keep that video's brief, assets, selected audio copy, captions, HyperFrames project, previews, exports, and release package inside that folder. Resume existing videos in their original folders. Separate videos get separate folders.
- Allowed rap/song generation providers: ElevenLabs Music or https://gemini.google.com. Honor the production's selected provider; for a new production without a selection, choose the available authorized route that fits the brief and record why. Gemini browser work uses the user's signed-in Brave session with Playwright/CDP. ElevenLabs UI/API access follows the user's available authorized setup. No specific Gemini model is required for new productions. The historical label “Argon” remains unverified; check it only if the current request or production explicitly requires it.
- Motion is authored as HyperFrames motion graphics in the user's chosen AI code editor. Keep editable HTML/CSS/JavaScript, local assets, motion.md, and the project setup together so another compatible editor can continue. Use the motion-graphics skill for suitable short units; assemble a full song through the HyperFrames music-to-video/general-video route while retaining the motion-graphics treatment. Prepare YouTube release assets as requested.

- Image generation may use either https://chatgpt.com or https://gemini.google.com through the user's authorized browser session. Choose per production and record the source. Music may use ElevenLabs or Gemini.
